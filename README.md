> I resign, effective immediately — consider this my two weeks' notice, backdated to the fortnight I spent secretly updating my résumé.

A one-line resignation letter with a twist: the "two weeks' notice" is backdated to the fortnight the employee spent secretly updating their résumé — quitting on the spot while pretending the notice period already happened.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (133 characters, no trailing newline).

Deterministic: no network, no randomness, no time dependence — every run produces byte-identical output.
